# Public-data and publication boundary

This is an allowlisted aggregate research repository, not a backup of the entire
private workspace. Frozen primary values remain complete; inferential eligibility
can be qualified without overwriting them.

Allowed: object/source descriptions, aggregate model coefficients/intervals,
bootstrap summaries, aggregate diagnostics, authored figures, Markdown and code.
Individual trial identifiers, raw clinical/expression inputs, individual influence
records, resampled indices, private contact details, secrets, private inventories, runtime
packages and third-party PDFs are excluded. The source-paper reference list does
not transfer redistribution rights. Locally supplied writing-skill code is excluded.

The archived v1.4 material was already reviewed for public release. An archive
label does not make private data safe: current validation scans it too. Public
figure reproduction is not a participant-level refit. A publication push is not a
journal submission or real-author sign-off.

For RPv5, the authors explicitly approved publication of their academic names,
affiliation, email contacts and ORCIDs, plus eligible project outputs. These
academic details may appear in the current manuscript; private profiles do not.
Only whitelisted generated DOCX/PDF documents are included. The private WP6
handoff ZIP and its machine-path audits are never uploaded wholesale. Approval
does not transfer rights in third-party participant inputs. Contribution roles
are not randomly assigned, and unrecorded historical AI identities stay unknown.
