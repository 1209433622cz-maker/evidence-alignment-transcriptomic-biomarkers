# Administration and scientific contracts

- `protocol/`: RPv4 and dated targeted-analysis/identifiability addenda.
- `analysis_plan/`: retained absolute-effect SOP; historical primary values are frozen.
- `templates/`: reusable provenance/estimand templates, not completed author sign-offs.
- `audit/`: public source/figure contracts, current status and curated audit evidence.
- `DATA_AND_PUBLICATION_BOUNDARY.md`: what is deliberately excluded.

Local expert-audit checks, current public validator checks and GitHub workflow results are separate events. The candidate remains author review; no fictional author metadata is supplied.
