# 0. 执行摘要与总体决策

## 0.1 核心判断

本项目已经从早期广泛评价肿瘤转录组治疗预测标志物，逐步收敛成一项围绕**原始临床主张、证据设计、标志物实现、受试人群与目标估计量是否一致**的实证研究。

现有工作建立了较完整的历史计算留存、来源追溯、样本身份核查、对象级解释重分类、定向模型重建及工程验证体系。

但这些工作不能自动保证稿件具有SCI二区期刊所要求的原创科学贡献。

当前主要问题是：虽然能够展示许多历史结果为何不应承担过强的治疗选择解释，但**尚缺乏集中、可定量展示“具体来源与分析差异如何改变结果”的系统化比较**。

因此，本计划决定：

**KEEP TOPIC — REPOSITION SCIENTIFIC QUESTION — TARGETED QUANTITATIVE ENHANCEMENT。**

即保留研究主题，调整主要结果体系，以AVAglio定向模型比较和TRIO随机化来源不可识别性为两个重点实证案例，以22项核心标志物的来源—证据—实现—人群—估计量矩阵形成完整方法学背景。

## 0.2 不推荐的处理方式

不建议直接把R5现有稿件作为科学内容完全冻结的最终投稿稿。

不建议重新回到全领域系统综述，更不建议重新寻找可能显著的新标志物来替换旧对象。

不建议为追求统计阳性而调整样本排除、阈值、终点、协变量或多重性规则。

也不建议继续仅凭机器验证PASS数量增加技术工作，取代真正的科学问题评价。

## 0.3 推荐的研究路线

**主路线：** 有限对象集来源—估计量对齐审计，加一项来源支持的定量模型纠正分析。

**重点实例A：** TRIO-US B07，说明统计计算可以完全复现，但随机分配阶段身份无法从公开数据中得到足够验证。

**重点实例B：** AVAglio，说明有来源依据的患者排除、缺失规则及模型调整可以改变估计结果，而必须区分不同变化来源。

**支持实例：** CHER-LOB、CIN70、revisedPARPi7、IGG14、RCC、GARD和BCI的原始主张与执行边界。

## 0.4 主要研究目标

本研究不再以“严格复制成功率”作为主要定量结论。

主要目标改为：

> 在一个事先固定的有限肿瘤转录组标志物对象集中，量化原始主张与历史推断资格的对应变化，并通过可追溯的定向模型比较，评价来源、人群和分析规格差异如何影响实际统计估计及其可支持的临床解释。

# 1. 研究背景与临床科学问题

## 1.1 肿瘤转录组标志物的临床价值

转录组标志物能够反映肿瘤增殖、免疫反应、间质组成、DNA损伤修复、细胞谱系及治疗应答相关生物学。

其临床应用可能包括预后评估、治疗条件下响应预测、治疗方案比较及治疗策略指导。

但这些用途需要不同的临床证据。

一种标志物与接受某治疗患者的响应有关，并不能直接证明该标志物可以帮助选择两种治疗中的哪一种。

同样，一个随机试验中的分子分析结果，是否能够解释为随机比较，还取决于实际分析人群是否属于相关随机分配阶段、分析使用了什么终点和模型，以及具体治疗比较是否与目标问题一致。

## 1.2 三种不能混淆的临床问题

**U1｜治疗条件下响应或结局关联**

例如：某标志物水平较高的患者，在接受特定治疗时是否更容易达到pCR？

它可以是重要的响应相关或预后相关问题，但本身不估计相对于另一治疗的差异获益。

**U2｜差异治疗获益**

例如：标志物水平是否改变治疗A相对治疗B的获益大小？

该问题通常需要合适的比较性设计、治疗与标志物交互估计，以及明确的人群与终点。

**U3｜标志物指导治疗策略的临床效用**

例如：按照该标志物选择治疗的策略，是否改善患者结局、减少毒性或提高净获益？

这又不同于单个治疗交互参数，需要与临床决策问题对应的证据。

本研究的重点是避免将U1、U2和U3自动等同。

## 1.3 为什么统计计算可重复仍不够？

分析脚本能够运行、系数可复现、P值一致，并不能证明：

1. 原始作者提出了与再分析相同的阳性主张；
2. 使用的评分完全对应原始检测函数；
3. 纳入的人群对应原始目标分析集；
4. 治疗对照与结局相同；
5. 统计参数回答了同一个临床问题；
6. 被称为“独立验证”的队列确实独立于原始报告。

任何一个环节不满足，都可能在数值正确的情况下产生过强解释。

# 2. 既有文献、知识空白与V4创新性

## 2.1 现有研究已经解决的问题

预测性标志物的试验设计、富集策略、交互估计及临床应用证据已有成熟方法学基础。

Vivot等2017年曾评价FDA相关肿瘤治疗标志物的临床试验设计和治疗—标志物交互证据。因此，单独提出“许多预测性主张缺少正式交互证据”，不是V4可以独占的原创发现。

PROGRESS研究框架讨论了分层医学研究的不同目的。

REMARK强调肿瘤标志物研究中人群、标志物测量、模型和结果报告的透明性。

ICEMAN提供判断效应修饰分析可信度的框架。

已有共享临床试验数据方法学工作也强调再分析目的、原研究设计与分析计划的对应。

## 2.2 本研究需要填补的更具体空白

本项目的拟议新增贡献不是重新发明交互模型，也不是把既有临床试验结果简单汇总。

它应当提供以下相互关联的实证信息：

**贡献一：历史计算与当前科学解释的版本化分离。**

对同一统计结果分别保留“历史上实际运行了什么”和“当前证据允许该结果解释成什么”。

**贡献二：来源差异的实质性纠正。**

不仅审查原文措辞，还实际核对分析集、评分来源、治疗对照和模型，并记录因此产生的解释或数值变化。

**贡献三：两种不同纠错路线的比较。**

TRIO属于历史数值保留、临床推断资格降低的情形。

AVAglio属于来源规则支持人群和模型恢复、因而需要重新评价统计估计的情形。

**贡献四：严格复制资格与统计阴性的分离。**

缺少可验证的人群、独立性或模型定义，可以造成复制比例不可估；这与经过合格验证后未发现效应不同。

## 2.3 V4必须证明的新增价值

最终稿件应明确回答：

- 此前的解释在哪些对象上发生了变化？
- 这些变化由何种证据差异触发？
- 哪些变化仅影响解释而不改变数值？
- 哪些变化触发真正的定向重算？
- 新旧模型差异可以描述到什么程度？
- 哪些差异仍无法确定原因？
- 这些经验对以后开展标志物研究和二次分析具有何种可执行的启示？

如果V4只能重复已有概念而没有新的可评价结果，应收缩论文范围，而不是继续增加复杂的工程门禁。

## 3.2 TRIO已有结果的意义

公共来源台账报告110个可关联的参与者记录，历史目标比较使用31名单药组和50名联合组，共81人。

原始试验存在先于随机分配的直接联合治疗阶段；相关来源报告中排除该阶段后的随机联合治疗组为38人。

历史公共台账没有提供足以逐人判定其随机阶段身份的权威字段。

因此，在这些集合定义对应的前提下，人数差异可以构成分析人群身份的警示，却不能定位任何特定参与者。

原历史模型可以作为计算历史保留，但不应成为已验证随机治疗效应修饰的证据。

## 3.3 AVAglio已有结果的意义

来源规则重建建立了三个人群层级：

- 349份表达可评价样本；
- 排除来源定义的10例IDH1突变后，339例IDH1野生型；
- 再排除6例相关临床协变量不完整记录后，333例完整病例。

当前已报告的333例来源协变量模型交互结果为：

| 标志物分类              | 交互HR  | 95% CI      | P值      |
| ------------------ | ----- | ----------- | ------- |
| Phillips proneural | 0.516 | 0.292–0.912 | 0.0229  |
| Verhaak proneural  | 0.460 | 0.261–0.811 | 0.00728 |

同时，研究明确使用来源保存的亚型标签，没有独立重跑原始centroid分类流程。

这些结果不是新的独立验证，也不能仅凭新旧P值差异证明某个单独纠错步骤引起了全部变化。

## 3.4 其余模型的当前角色

CHER-LOB的结果继续作为独立的单试验分析记录，不因TRIO身份问题而自动失效。

GBM跨试验比较仍须考虑AVAglio与GLARIUS在人群、治疗背景及可用协变量方面的差异。

CIN70、IGG14、revisedPARPi7、RCC、GARD和BCI需要持续保留各自的原始主张、评分实现、独立性和统计估计量限制。

特别是BCI已有正式发表的阳性治疗交互证据，但这并不意味着本地简化评分能够精确重建完整临床检测方法。

## 3.5 当前严格复制比例的边界

因此当前严格复制比例为不可估，不能写成0%、0/0或0/3，也不能转化成全领域复制失败的结论。

# 5. 核心科学问题、目标与假设

## 5.1 总科学问题

在固定的肿瘤转录组标志物对象集中，原始主张、实际证据设计、评分实现、人群身份和验证估计量之间的差异，如何改变历史分析所允许的临床推断？

当来源规则可以恢复时，采用不同分析人群和模型又如何改变统计估计与其不确定性？

## 5.2 具体研究目标

**Aim 1：** 构建22项核心对象的主张—证据—实现—人群—估计量对应矩阵。

**Aim 2：** 量化历史解释与当前推断资格之间的变化，明确变化原因和依赖结构。

**Aim 3：** 在AVAglio中分步比较分析集与协变量模型变化对交互估计的影响。

**Aim 4：** 为TRIO建立不依赖患者身份猜测的可识别性分析及明确的分析终止规则。

**Aim 5：** 重新组织历史交互、绝对效应和跨试验结果，将其与可支持的临床问题对应。

**Aim 6：** 输出可审计的分析协议、源表、代码、图件及解释限制，使结果具有明确的复核路径。

## 5.3 工作性假设

**H1：** 历史统计结果能够复算与当前推断资格相符，是两个不同条件。

**H2：** 来源支持的患者集合和模型恢复，可以改变交互估计及区间；不同步骤的影响需要使用可比分析集和模型加以描述。

**H3：** 标志物原始用途、结果性质及独立验证身份的审计，可以识别历史解释过度升级的情形。

**H4：** 严格验证资格不足可能导致目标比例不可估，而不是统计效应等于零。

这些假设作为V4工作的组织框架，不追溯性声称其在历史结果未知时已被前瞻冻结。

## 5.4 主要研究产出

主要产出为**对象级推断资格变化及其原因的可追溯实证矩阵**。

核心量化实例为AVAglio来源规则与模型规格的增量比较。

历史27个交互、23个绝对效应及13个跨试验单元作为完整支持证据保留。

不以新增统计显著结果作为研究通过标准。

# 6. 研究设计与对象选择

## 6.1 研究类型

Finite retrospective empirical methods study with provenance auditing and targeted secondary reanalysis。

不称为新前瞻随机试验、临床预测模型开发、全领域系统综述或全面独立外部验证。

## 6.2 固定的研究对象层级

研究保留五类标识：

| 层级     | 核心字段                        | 作用           |
| ------ | --------------------------- | ------------ |
| 文献报告   | report_id / DOI / version   | 原始证据与措辞定位    |
| 主张—估计量 | claim_estimand_id           | 22项核心审计对象    |
| 标志物实现  | implementation_id / version | 评分函数和标签来源    |
| 试验及人群  | trial_id / population_id    | 分配机制、治疗对照和结果 |
| 统计模型   | model_id / source_data_hash | 历史模型与新分析版本   |

这五类单位分别计数。

同一标志物在两个试验中的两行模型，不是两个独立标志物主张。

## 6.3 研究对象形成过程

保留28项历史候选、22项核心对象及15项具有本地模型记录对象的既有谱系。

V4-S1必须逐条说明其余6项未进入核心的原因，记录选择规则形成日期及当时已经可见的结果。

不能因V4分析方向调整而事后重新筛选有利对象。

## 6.4 选择偏倚说明

核心对象集来自历史目的性选择，不构成对整个肿瘤转录组治疗标志物领域的概率抽样。

可以报告：

“在本研究预先界定的22个对象中，具有某种审计角色的对象数为N。”

不能报告：

“全领域N%的转录组标志物存在某种问题。”

对象间还可能共享试验、标志物家族、文献和证据，因此本研究的简单比例主要是集合内描述量，不采用将22项当成独立随机样本所产生的总体置信区间。

# 7. 来源审计与对象分类体系

## 7.1 原始用途分类

| 类型 | 定义           | 示例问题                |
| -- | ------------ | ------------------- |
| U1 | 治疗条件下响应或结局关联 | 接受治疗A的人群中M是否与pCR相关？ |
| U2 | 治疗之间的差异获益    | M是否改变A相对B的效应？       |
| U3 | 标志物指导策略效用    | 根据M选择治疗是否改善患者结局？    |
| U0 | 原始临床用途无法明确恢复 | 原文用途表述不清或不足         |

## 7.2 原始结论性质独立编码

原始用途不等于原始结论为阳性。

另设：

- POSITIVE_SOURCE_CONCLUSION；
- NEGATIVE_SOURCE_CONCLUSION；
- EXPLORATORY_OR_HYPOTHESIS_GENERATING；
- TESTED_ONLY_NO_POSITIVE_CLAIM；
- AMBIGUOUS_OR_UNRECOVERABLE。

U1、U2等用途与阳性、阴性、探索等结论必须分别记录。

例如，某个U1标志物可以在原始研究中得到阴性结果，不能因此变成U0。

## 7.3 证据设计独立编码

区分：

- 随机比较及正式交互；
- 随机试验中的单治疗臂响应关联；
- 随机试验中的亚组比较，但正式交互未明确报告；
- 非随机比较；
- 单臂观察；
- 标志物策略随机试验；
- 发表聚合证据；
- 研究设计不清或无法恢复。

试验整体随机化，不自动证明该论文实际分析的每个分子子集都具有已验证随机比较资格。

## 7.4 实现忠实度

保留历史F0–F4分类体系，不覆盖原始等级。

增加独立实现来源字段：

| provenance_type            | 定义               |
| -------------------------- | ---------------- |
| SOURCE_FUNCTION_REEXECUTED | 实际重新执行原始评分或分类函数  |
| SOURCE_LABEL_REUSED        | 直接使用来源已保存的分类标签   |
| AUTHOR_SCORE_REUSED        | 直接使用作者发布的连续或分类分数 |
| APPROXIMATE_RECONSTRUCTION | 执行明确标注差异的相容近似    |
| PARTIAL_IMPLEMENTATION     | 仅部分原始函数可恢复       |
| NOT_EXECUTABLE             | 关键执行要素缺失，无法恢复    |
| UNKNOWN                    | 尚无足够审计证据         |

该字段与历史F级别正交，不能直接替代F0–F4。

尤其不能将SOURCE_LABEL_REUSED自动当成完整算法精确复算。

## 7.5 人群与随机性

设定人群身份状态：

- VERIFIED_RANDOMIZED；
- VERIFIED_NONRANDOMIZED；
- KNOWN_MIXED；
- ALLOCATION_UNVERIFIED；
- UNKNOWN；
- NOT_APPLICABLE。

同一研究可能存在不同时间、治疗分配方式和分子可评价人群。

对于每项推断，需记录具体人群ID与来源依据，不使用试验名称自动填充随机身份。

## 7.6 独立验证身份

独立性必须带有参照对象：

- 相对于标志物定义或训练集是否独立；
- 相对于原始主张论文分析样本是否独立；
- 相对于已发表验证论文是否独立；
- 是否共享试验或参与者；
- 是否存在同一治疗比较与终点；
- 是否存在明确的实现或估计量差异。

不能把“来自另一份GEO文件”自动等同于独立临床验证。

# 10. TRIO-US B07专项：分析人群可识别性与补救

## 10.1 现有事实

TRIO的原始设计存在非随机直接分配的联合治疗导入阶段。

历史公共台账具有110个治疗与结局可关联记录，但无法由已知字段恢复全部受试者的随机分配阶段身份。

历史目标比较使用81人，其中50人为联合治疗组。

来源报告排除非随机导入阶段后的对应随机联合组为38人。

这一集合差异提示历史分析集不能在未经进一步验证时视为完全随机。

## 10.2 V4主要问题

**能否从权威来源恢复历史模型中每个参与者是否属于目标随机分配阶段？**

如不能，允许什么样的统计描述，又必须停止哪些因果解释？

## 10.3 权威身份证据

可接受的证据包括：

- 官方试验数据字典中的随机化阶段字段；
- 与参与者键有真实对应的权威分配表；
- 原研究者或数据管理方提供、可核对的授权映射；
- 与原始试验报告一致的版本化来源说明。

不可接受的证据包括：

- 按患者ID大小或排序推断；
- 按样本上传顺序推断；
- 按治疗反应或表达模式推断；
- 为凑足38人而主观选择联合组子集；
- 依照哪个子集产生更小P值作选择。

## 10.4 可能的实际补救

**分支A：权威映射可以恢复。**

首先冻结完整映射、样本排除规则与比较定义，再对受影响的10个历史签名在新版本执行定向分析。

**分支B：映射仍不能恢复。**

维持历史81人模型的数值历史角色，不生成虚构的随机分析集。

**分支C：敏感性或部分识别研究可行。**

仅在有足够已知约束时计算不依赖个体身份猜测的结果范围；如果约束不足以识别治疗×标志物交互参数，应明确“该参数在当前资料下不可识别”。

可以用独立合成数据模拟说明阶段混合带来的潜在影响，但不可将模拟结果称作TRIO的真实纠正估计。

## 10.5 当前统计解释

若公共联合组50行与原报告的随机联合组38例定义完全对应，则两者的人数差提供集合层面的不一致信息。

该条件不意味着可以识别具体非随机个体，也不应据此直接把恰好12行删除。

不能从该人数关系推断真正的随机治疗效应交互参数。

## 10.6 完成标准

TRIO专项可以通过以下任一科学分支结束：

- 权威随机身份恢复，执行并审计合法定向重算；
- 权威身份未恢复，保留明确的不识别结论和受限历史估计；
- 仅进行事先冻结、不会冒充真实因果估计的敏感性演示。

不以“必须恢复38人”作为成功条件。

- IDH1人群限制；

## 11.3 推荐模型序列

| 分析ID | 分析人群        | 模型                 | 研究问题        | 当前状态         |
| ---- | ----------- | ------------------ | ----------- | ------------ |

| A3   | 333例完整病例    | 来源协变量调整模型          | 相同样本下模型规格差异 | 已完成（Q2-R3）    |

## 11.4 模型序列的解释限制

建议使用共同的终点、治疗组方向、时间尺度和亚型标签。

比较A0与A1时，模型结构尽可能不变，以描述人群范围差异。

比较A1与A2时，保持模型结构一致，以描述完整病例限制产生的变化。

比较A2与A3时，在相同333例中比较模型规格。

**这些比较是模型敏感性描述，不等同于因果归因。**

尤其应指出：

- Cox HR具有非可折叠性；
- 调整与不调整模型的HR差异不能全部解释为混杂被消除；
- 排除病例可能改变协变量分布及风险集；
- 模型比较中的效应差异还受参数化、样本信息和不确定性影响。

不得以P值是否跨越0.05单独评判哪一步分析更“正确”。

## 11.5 统计模型

对于第i名参与者：

`h_i(t) = h_0(t) × exp(βT × T_i + βM × M_i + βTM × T_i × M_i + γᵀ X_i)`

其中：

- T为实际治疗比较编码；
- M为来源分型或标志物编码；
- X为当前模型所规定的协变量；
- `exp(βTM)`为对应模型中的治疗×标志物交互HR。

这一HR不是某个标志物亚组内的治疗HR，也不是治疗选择策略的净临床效用。

## 11.6 必须锁定的模型细节

每个模型记录：

- 样本入选及排除依据；
- n与事件数；
- 生存时间单位；
- OS事件及删失编码；
- 治疗变量方向；
- Phillips/Verhaak分类编码；
- 协变量名称、类型及参考组；
- 缺失值处理；
- Cox并列事件处理方法；
- 标准误、区间及P值算法；
- 惩罚方法和惩罚系数；
- 软件及版本；
- 输入和输出哈希。

## 11.7 339例ridge敏感性的重点核查

六例协变量不完整记录不能仅依靠ridge惩罚自动变成完整数据。

应检查实际代码究竟采用：

- 缺失协变量处理；
- 某些变量的替代规格；
- 协变量子集；
- 其他明示的处理方法。

如果339例模型与333例模型的实际协变量不同，应明确称为替代规格敏感性分析，而不是单纯相同模型加入惩罚项。

不得未经源代码证实而写入“多重插补”。

## 11.8 建议的稳定性诊断

在现有数据支持下检查：

- 比例风险假设；
- 随访时间及事件编码；
- 稀疏类别与模型收敛；
- 高影响参与者；
- 两套分型标签的一致与差异；
- 重要协变量的缺失及编码；
- 指定分析集上的结果稳定性。

诊断不通过时应报告真实问题，不通过逐步删除个体寻求显著。

## 11.9 新旧估计变化的呈现

优先展示所有模型的交互估计及95% CI。

如进一步报告系数差异，应使用清楚的共同方向、对应样本集和适当的不确定性评价。

可在技术可行时采用参与者层面配对重采样评估模型差异的不确定性，但必须预先明确重采样规则、共享患者、有效重复次数及收敛问题。

此类结果仍是模型规格敏感性，不构成模型改变的因果效应估计。

## 11.10 新分析多重性

V4新增A2模型及任何尚未执行的模型差异不确定性分析，均属于已经观察过相关数据后的方法学敏感性研究。

历史冻结P/q不能直接移作新增模型的多重性结论。

V4-S0应明确新模型组成的探索性检验家族，完整报告所有结果；不以校正后是否显著作为决定执行与否的依据。

## 11.11 完成标准

AVAglio专项必须形成：

- 所有已运行模型的同一口径结果表；
- 349、339、333实际分析集对应；
- 新旧模型规格差异表；
- 完整不确定性及模型诊断；
- 对不可估项目的明示记录；
- 旧结果与V4新结果分别保存；
- 可通过源表重新生成的图件。

若A1或A2因源变量不可恢复而不可执行，应形成有依据的终止裁决，不补造结果。

## 12.1 CHER-LOB

# 13. 统计分析总方案

## 13.1 U1：治疗条件下响应关联

二元响应的示例模型：

`logit[P(Y=1 | T=t, M, X)] = αt + γt M + δᵀX`

该模型在指定治疗条件下回答M与响应是否有关。

它不直接回答治疗A相对B的差异获益。

## 13.2 U2：治疗效应修饰

二元结局示例：

`logit[P(Y=1 | T,M,X)] = α + βT T + βM M + βTM(T×M) + δᵀX`

其中βTM是所定义模型的治疗×标志物交互系数。

对于生存结局，可使用包含相同科学对象的Cox交互模型。

必须报告治疗编码、标志物编码、参数尺度及完整95%区间。

## 13.3 绝对风险尺度

保留既有标准化风险差敏感性：

`RD(m) = P(Y=1 | T=1, M=m) − P(Y=1 | T=0, M=m)`

`ΔRD = RD(Q75) − RD(Q25)`

其中预测概率的标准化目标人群、协变量分布和标志物定义必须明确。

绝对尺度和比值尺度可以得到不同交互结论，不能事后只挑选更显著的一种尺度。

## 13.4 生存结局与比例风险

对Cox模型应说明：

- 时间起点；
- 删失规则；
- 协变量调整；
- 比例风险假设；
- 是否存在时间变化效应迹象；
- 参数的具体解释。

如果PH假设明显不满足，可作事先定义且有临床意义的替代描述，但不得无条件将某个后选时间点结果升级为新的主要证据。

## 13.5 统计精度与区间

非显著P值不证明无效、等价或没有临床重要差异。

应优先报告估计值、置信区间、信息量、样本与事件数。

不使用依据观察效应计算的事后检验功效作为主要解释理由。

## 13.6 多重比较

保留历史模型原始检验家族和BH等校正结果。

V4新增检验作为新的探索性分析层，列清全部相关模型、家族和校正结果。

27个历史模型、23个绝对效应及13个跨试验单元不应在未说明其依赖结构的情况下合并计算新的统一发现率。

## 13.7 小样本与计算失败

记录：

- 收敛；
- 分离；
- 极端参数；
- 重采样有效比例；
- 稀疏事件；
- 估计不可得；
- 模型敏感性。

“模型不可估”“区间宽”“P未显著”“估计量不兼容”“原文主张为阴性”均为不同状态。

## 13.8 版本间差异

每次新分析输出：

`old_model_id、new_model_id、input_change、population_change、formula_change、beta_old、beta_new、intervals、reason、version_hash`

不允许只保存新P值而删除历史模型。

# 14. 可选模拟研究：仅在具有独立增量价值时开展

## 14.1 模拟的研究问题

在真实随机分配阶段与非随机导入阶段混合且未被正确识别的情况下，将全部数据误当作单一随机分析集，可能如何影响治疗×标志物交互估计？

## 14.2 启动门槛

只有满足以下条件时执行：

1. TRIO真实随机身份仍不可恢复；
2. 模拟能够回答一个现有实证分析不能直接回答的问题；
3. 比较方法和数据生成机制可以明确定义；
4. 已经冻结ADEMP方案；
5. 不会把模拟结果当成真实患者级估计。

不因为模拟图形能增加投稿包复杂度就启动。

## 14.3 ADEMP框架

**Aims：** 评价随机分配阶段混合对治疗效应修饰估计的影响。

**Data-generating mechanisms：** 设置基线预后、标志物分布、治疗分配阶段、响应概率、样本选择过程和真实交互效应。

**Estimands：** 在已定义目标人群下的交互系数或绝对风险异质性。

**Methods：** 错误混合分析、具有真实阶段信息的正确分析、预先定义的敏感性方法。

**Performance measures：** 偏倚、95%区间覆盖率、错误阳性率、均方误差、功效及模型失败率。

## 14.4 实验设计

考虑真实交互为零或非零、不同非随机阶段占比、不同阶段的患者特征差异及不同样本规模。

参数设置来自合理的临床与统计场景，不直接使用真实TRIO未识别身份进行反推。

完整保存随机种子、重复次数、代码、模拟真值与Monte Carlo误差。

## 14.5 解释限制

模拟只能说明在设定假设下方法可能出现何种偏差。

它不能恢复TRIO实际随机受试者，也不能成为临床治疗选择推荐。

## 14.6 终止规则

若试运行显示仅重复已知结论、没有清晰新方法问题或无法实现可靠性能评价，可以取消该模块，并保存取消理由。

取消模拟不构成主研究失败。

# 16. 质量控制与独立复核

## 16.1 QC分层

**Layer 1：文件与版本完整性**

检查文件存在、大小、哈希、manifest和历史版本不变性。

**Layer 2：来源与实现身份**

核对原始论文、勘误、公式、作者评分与标签来源。

**Layer 3：统计计算**

核对分析人群、模型规格、事件、参数方向、估计值、区间及收敛。

**Layer 4：科学解释**

判断估计量、人群身份、独立性和原始主张是否一致。

**Layer 5：稿件与图件**

检查正文、表格、图注和实际图形是否陈述同一科学结果。

机器文件验证通过，不能自动使Layer 4通过。

## 16.2 关键对象复核

优先复核可能实质改变主要结论的来源及分析：

- TRIO随机化身份；
- AVAglio分析人群和协变量；
- CIN70原始二分类与连续结果；
- DOP原始人群；
- BCI发表证据与本地实现；
- 当前严格验证资格。

如没有真实独立复核人员，不应虚构双人盲审或人工批准。允许作者级定向复核，但须明示实际流程及其限制。

## 16.3 数值验收

对于历史冻结结果，使用原始既定容差和哈希规则保护历史复现。

对于新增V4结果，按模型拟合软件、优化方法和精度建立独立对照标准，明确允许的浮点容差。

新模型不需要产生与旧模型完全相同的数值；其目的正是验证有依据的规格变化。

## 16.4 图件验收

同时检查：

- 科学内容；
- 单位与坐标；
- 误差线；
- 方向；
- 图注；
- 字号；
- 裁切；
- 线宽；
- 色觉可访问性；
- 最终期刊版心；
- 矢量格式；
- source-data可追溯性。

“高分辨率”不是“最终可读”的充分条件。

# 19. 建议的最终论文写作逻辑

## 19.1 Introduction

按以下顺序：

1. 转录组标志物的临床价值；
2. 响应关联、差异治疗获益和策略效用的区别；
3. 已有研究对交互证据和报告透明性的贡献；
4. 现有二次分析容易忽略的来源、实现及人群问题；
5. 本研究为何采用有限对象集；
6. 本文实际新增的实证问题。

不把工程复杂性当成创新性主张。

## 19.2 Methods

建议依次：

1. 研究设计及历史分析时间顺序；
2. 对象形成和来源追溯；
3. 原始主张用途及结论性质；
4. 实现来源和忠实度；
5. 人群身份与随机性；
6. 历史模型与当前解释；
7. TRIO身份审计；
8. AVAglio模型序列；
9. 绝对效应、跨试验独立性和多重性；
10. 敏感性/模拟（如执行）；
11. 数据、代码、伦理及再现性。

## 19.3 Results

推荐顺序：

1. 有限对象集与审计单位；
2. 22项对象的原始主张和角色对应；
3. TRIO：数值可复算、随机阶段不可验证；
4. AVAglio：来源规则重建与模型序列；
5. 其他对象的实现、独立性及估计量差异；
6. 历史交互和绝对效应的当前解释；
7. 跨试验复制资格与不可估边界；
8. 对临床研究方法的总体实证启示。

结果章节应以科学发现为主，不按内部代码运行顺序罗列PASS数量。

## 19.4 Discussion

首先回答：

**来源、实现、人群和估计量审计，究竟改变了哪些结论？**

其次讨论：

- 可重复计算与可信临床推断的区别；
- TRIO与AVAglio为何代表两种不同的纠正结果；
- 与现有肿瘤预测标志物研究的区别；
- 研究对象目的性选择的限制；
- 无法恢复的随机身份及评分实现；
- 临床决策层面尚缺少的独立证据；
- 可推广的审计操作原则。

不把P值变小称为某种生物学机制已经被验证。

## 19.5 Conclusions

限定在：

**对选定肿瘤转录组标志物进行临床解释时，来源、实现、人群及估计量对齐与数值计算可重复性同样重要。有依据的纠错可改变统计结果或推断资格，但两者必须分别记录和评价。**

不宣称本研究开发了新的临床标志物或证明所有历史标志物失败。

## 20.2 暂不冻结具体期刊

BMC Medical Research Methodology可作为条件性候选，其方法学范围与研究方向相关，但对于选定已发表研究汇总分析的文章类型存在准入风险。

本研究应如实强调实际来源核查、公共临床数据重建和定向模型比较，而不是为了投稿改称未开展的系统综述。

是否符合Research Article范围，需要根据期刊实际政策或编辑反馈确认。

## 20.3 SCI二区分区要求

必须明确采用：

- JCR分区或中科院分区；
- 具体统计年度；
- 作者单位实际采用的评价政策。

不从影响因子、出版社或文章类型直接推断分区。

## 20.4 投稿可行性条件

论文能否达到目标水平，取决于：

1. 科学问题是否集中；
2. 新增模型比较是否形成真实实证增量；
3. 当前所有主张是否与来源证据严格对应；
4. 主要图表是否清楚；
5. 统计限制是否透明；
6. 目标期刊是否接受有限实证方法学设计。

本计划不设定没有数据支持的录用概率。

# 23. 可行性、资源分配与停止规则

## 23.1 优先级

**最高优先级：** V4-S0与S1的分析定义、对象角色变化表。

**第二优先级：** AVAglio新增A1/A2模型的输入和统计可行性。

**第三优先级：** TRIO权威随机身份进一步恢复的可能性。

**第四优先级：** 根据实际新增信息决定是否开展模拟。

**第五优先级：** 主稿和主图重新设计。

不先消耗资源重新生成已经正确的27个历史模型。

## 23.2 资源约束

V4不要求采购新的测序数据或训练大规模深度学习模型。

不以新增全领域文献检索、机器学习框架或多个无关疾病模块作为进入下一阶段的前提。

现有试验数据与合法访问权限仍须逐项确认。

## 23.3 停止规则

若AVAglio中间模型不能有依据地运行，停止该模型，不通过修改阈值和样本选择寻求数值。

若TRIO随机身份不能恢复，停止纯随机纠正分支，不进行虚构的患者级识别。

若模拟不能提供新增科学信息，取消模拟。

若全面V4论文范围过宽或增量结果不足，则优先收缩为TRIO和AVAglio双案例方法学研究。

只有在收缩方案仍缺乏可独立发表的贡献时，才讨论重新选题。

# 25. 成功、失败与论文收缩路线

## 25.1 完整V4可行

如果AVAglio增量模型形成有用且可解释的数值对照，同时22项审计矩阵能够支持清楚的方法学发现，则继续完整V4研究。

此时投稿重点为有限实证方法学研究。

## 25.2 双案例收缩

如果核心新模型受数据约束而无法充分分解差异，但TRIO的解释降级和AVAglio的来源模型重建仍有可靠实证价值，则考虑收缩为双案例研究。

22项对象矩阵保留为支持材料，而不是强行扩张成领域总体。

## 25.3 不支持继续的情形

如果发现主要结果或来源身份存在无法解释、影响核心结论的实质冲突，暂停相应主张。

仅针对具体冲突重新核查数据和代码，不重写结果来维持预期结论。

## 25.4 选刊失败不是科学失败

如果某期刊不接受有限实证方法学文章，应优先寻找更合适的文章类型或方法学期刊。

不应为适应期刊而把真实回顾性研究改写成前瞻性注册研究，也不应改造成未经独立验证的新标志物发现论文。

# 26. 最终结论与下一阶段

## 26.1 研究方向裁决

**保留主题，调整论文主要科学问题。**

本项目现有证据追溯、统计重建和数值保存工作具有进一步利用价值。

但如果主要结果仍然围绕历史交互阴性数量和严格复制比例不可估展开，方法学原创贡献可能不够集中。

V4将主要重点转移到：

1. 22项对象的历史→当前推断资格变化；
2. AVAglio来源规则驱动的统计模型比较；
3. TRIO分析人群不可识别性的严格解释；
4. 对临床转录组标志物二次分析的可操作方法学教训。

## 26.2 最优下一阶段

**V4-S0/S1：历史结果冻结、角色变化量化与AVAglio增量分析预检。**

该阶段不要求立即重新生成全部稿件图表。

首先确保下一步新分析确实回答可识别的科学问题，并且输入数据、统计规格和成功/失败规则都已经冻结。

## 26.3 Go/No-Go判断

**GO：** 研究主题保留，启动V4科学方案预检与对象级角色量化。

**CONDITIONAL：** AVAglio增量模型是否提供充分新信息，必须依真实运行结果判断。

**HOLD：** 正式投稿文件、GitHub同步及投稿。

**NO-GO：** 无授权重构TRIO随机样本、结果导向阈值选择、伪造独立验证或覆盖历史输出。

## 26.4 本版本效力

本计划书是新的科学方案建议。

它不自动覆盖Q2-R5已接受结果，不自动修改公开GitHub，不自动授权新的患者数据访问，也不代表V4新增模型已执行。

只有研究责任人批准新增分析规则并完成相应版本冻结后，V4-S0及后续分析才能作为新的实际执行依据。
