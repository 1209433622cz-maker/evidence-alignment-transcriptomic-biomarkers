## 3. 预先冻结的事实与条件

1. 方案规定最初 20 名合格参与者直接分配至 Arm 3；之后的参与者在 Arm 1、2、3 之间随机分配。
2. 发表报告的 ITT 人群为 Arm 1=34、Arm 2=36、Arm 3=58；Arm 3 总体 pCR 为 30/58；排除最初 20 人后，随机 Arm 3 为 21/38。
3. 公开 `preTreatment.txt` 观察到 110 行：Arm 1=31（pCR 15）、Arm 2=29（pCR 7）、Arm 3=50（pCR 25）。
4. 公开作者仓库没有 `assignment_phase`、`randomized`、`lead_in` 或等价的患者级阶段字段。
5. 以下集合约束仅在“公开 Arm 3 的 50 行属于发表 Arm 3 的 58 人，且 pCR 定义一致”的条件下计算。

## 4. 预先冻结的集合级计算

令：

- `r` = 公开 Arm 3 表达子集中来自随机阶段的人数；
- `s` = 上述 `r` 人中的 pCR 数。

由于发表 Arm 3 包含 38 名随机参与者和 20 名直接分配参与者，而公开表达子集有 50 人：

`30 ≤ r ≤ 38`。

由随机阶段 pCR 总数 21、非随机阶段 pCR 总数 9，以及公开表达子集 pCR 总数 25，可得：

`max(16, r-17) ≤ s ≤ min(21, r-14)`。

这些是整数相容性边界，不是抽样置信区间、因果界或 treatment×marker 交互界。

## 5. 分析与停止规则

1. 独立读取 `preTreatment.txt` 与 110 行台账，核对行数、唯一性、治疗臂、pCR、字段存在性和 source hashes。
2. 枚举全部整数相容组合，并由第二份独立脚本复算。
3. 不生成任何患者级阶段标签，不按编号或顺序删除患者，不拟合伪造的“随机 Arm 3=38”模型。
4. 若没有权威患者级映射：冻结 `TRIO_RANDOMIZATION_IDENTITY_NOT_RECOVERABLE_FROM_CURRENT_PUBLIC_EVIDENCE`，纯随机交互分支终止。
5. Arm 1/2 可由试验设计判定为随机来源；Arm 3 仍为混合阶段可能，故含 Arm 3 的历史 31/50 比较不具备纯随机资格。
6. 只有作者、试验数据保管方或等价权威来源提供可追溯的患者级阶段映射，才允许重开定向重跑。
7. 模拟仅在能回答新的方法学性能问题时执行；若只是展示未知混合可改变结果，则取消并记录理由。
