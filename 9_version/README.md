# Version history

`VERSION_HISTORY.json` records the active v1.5 author-review interface, its prior
public commit and the location of the coherent v1.4 snapshot. Git history is
preserved. Values and labels were not modified for this repository migration.

The original private workspace and the public tree have different contents and
paths by design. Relative links, byte contracts, public validation, remote commit
verification and journal release status are separate facts.
