# Figure filing convention

Fig1–Fig4 contain current main figures. Fig5/6/7 are filing locations for
supplementary S1/S2/S3, **not** new main Figures 5–7. Fig8 is reserved.
Each active figure is available as PDF, SVG and 600-dpi PNG in `current_v1.5/`.

All 27 primary and 23 absolute rows are retained in supporting forests. Selection
uses scientific role rather than P value. Prior figures, systematic-review
placeholders and superseded inference headlines are stored in the coherent
v1.4 archive. Figure-only PDF QA does not imply whole-manuscript WPS approval.
