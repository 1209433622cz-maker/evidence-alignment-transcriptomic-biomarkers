# Scientific rationale

The project began with prospective attempts to identify reproducible treatment
response biology in TGCT, GIST, GBM and breast-cancer randomized trial data.
Prespecified replication and novelty gates repeatedly stopped candidate papers
when results did not support the intended claim. Those negative decisions were
retained instead of being rescued through outcome-driven gene selection,
cut-point optimization or post-hoc model training.

The resulting meta-research question is stronger: when the oncology literature
uses predictive or treatment-selection language for a transcriptomic biomarker,
are claim wording, original evidence class, executable formula, randomized
comparison, estimand, data availability and independent evaluation aligned?

The nested randomized benchmark is one empirical layer of this question. It is
not a substitute for the outer systematic evidence map.

## Frozen evidence domains

1. **Claim/evidence alignment** — whether published treatment-selection
   language is supported by formal randomized interaction evidence.
2. **Executability/evaluability** — whether the biomarker formula can be
   reconstructed faithfully and mapped to a compatible randomized comparison.
3. **Validation maturity** — whether an independent, interval-supported test
   of treatment-effect modification exists.

No composite readiness score is used. Each axis is reported separately so a
strong result in one domain cannot conceal failure or indeterminacy in another.
